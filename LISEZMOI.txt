SITE — EDOUARD RICHARD, PHOTOGRAPHE SPORTIF
===========================================

Le site est construit avec Astro. Astro assemble les fichiers de src/ et
produit un site entierement statique dans dist/ : le resultat mis en ligne
reste du HTML simple, sans base de donnees et sans serveur a faire tourner.


CONTENU
  src/data/series.ts      LES PHOTOS ET LES SERIES — c'est ici qu'on travaille
  src/pages/index.astro   l'assemblage de la page
  src/components/         les morceaux de page (menu, galerie, contact...)
  src/layouts/Base.astro  l'en-tete HTML commun (titre, apercus de lien)
  src/styles/global.css   toute l'apparence
  src/scripts/site.js     la mosaique, la visionneuse, le panneau Reglages
  public/images/          les 25 photographies
  public/                 favicon, og-image, robots.txt
  astro.config.mjs        l'adresse du site, un seul endroit a changer
  netlify.toml            construction et cache
  dist/                   le site fabrique — ne pas modifier, ne pas versionner


-------------------------------------------------------------------------
1. TRAVAILLER SUR SON ORDINATEUR
-------------------------------------------------------------------------
Il faut Node.js (version 20 ou plus) installe une fois pour toutes.

  npm install       la premiere fois seulement
  npm run dev       ouvre le site sur http://localhost:4321
  npm run build     fabrique le site dans dist/
  npm run preview   affiche le resultat de build

Avec "npm run dev", chaque enregistrement de fichier rafraichit la page
automatiquement.

Note : on ne peut plus ouvrir le site en double-cliquant un fichier, comme
avant. C'est la contrepartie du passage a Astro : il faut passer par
"npm run dev", ou simplement regarder le site en ligne.


-------------------------------------------------------------------------
2. AJOUTER UNE PHOTO
-------------------------------------------------------------------------
Deux gestes, et rien d'autre.

  1. Deposez le fichier JPEG dans public/images/
  2. Ajoutez une ligne dans la serie voulue, dans src/data/series.ts :

     { file: 'basketball-07-tir-au-buzzer.jpg',
       cap:  'Tir au buzzer',
       meta: 'Rouen–Caen · 12.03.26',
       alt:  'Tir au buzzer — basketball, Rouen contre Caen' },

Ce qui se met a jour tout seul, sans y penser :
  - les dimensions de l'image, lues dans le fichier lui-meme ;
  - le numero de la photo (01, 02, 03...) selon sa place dans la liste ;
  - le compteur de la serie, dans le menu, sur la vignette et sur le titre ;
  - le total de photographies affiche en page d'accueil.

Conseils d'export : JPEG, 1600 a 2000 px de large, qualite 80 %, soit 300 a
600 Ko. Nom de fichier sans accents ni espaces. Les .HEIC d'iPhone ne
s'affichent dans aucun navigateur : exportez en JPEG.


-------------------------------------------------------------------------
3. REMPLACER OU SUPPRIMER UNE PHOTO
-------------------------------------------------------------------------
REMPLACER : deposez le nouveau fichier dans public/images/ avec exactement le
meme nom que l'ancien. Rien a changer dans le code, meme si les proportions
sont differentes.

SUPPRIMER : effacez sa ligne dans src/data/series.ts. Le fichier image peut
rester dans public/images/, il ne sera simplement plus affiche.

REORDONNER : deplacez les lignes dans src/data/series.ts. Les numeros suivent.


-------------------------------------------------------------------------
4. AJOUTER UNE SERIE
-------------------------------------------------------------------------
Dans src/data/series.ts, ajoutez un bloc sur le modele des autres : un id
(sans accent ni espace), un chiffre romain, un titre, un libelle court pour le
menu, un lieu, une periode, une image de couverture et la liste des photos.
Le menu, les vignettes et la galerie apparaissent d'eux-memes.


-------------------------------------------------------------------------
5. MODIFIER UN TEXTE
-------------------------------------------------------------------------
Les textes vivent dans src/components/, un fichier par morceau de page :

  Hero.astro          le grand titre d'accueil
  Statement.astro     « Le travail », les chiffres, le materiel
  Atelier.astro       la presentation, les prestations
  Contact.astro       le formulaire et les coordonnees
  Footer.astro        le bas de page
  Nav.astro           le menu

Cherchez la phrase, remplacez-la, sans toucher a ce qui est entre chevrons.


-------------------------------------------------------------------------
6. L'APPARENCE ET LE CSS
-------------------------------------------------------------------------
Le panneau « Reglages » est reserve au proprietaire du site. Les visiteurs
n'ont qu'un bouton rond soleil / lune, qui bascule clair / sombre.

Pour afficher le panneau sur VOTRE navigateur, ouvrez le site une fois avec
?reglages a la fin de l'adresse :

    https://edouardvisuals.com/?reglages      ouvre l'acces
    https://edouardvisuals.com/?reglages=0    le referme

Le bouton « Reglages » et le raccourci clavier R apparaissent alors, et le
restent sur cet appareil. L'adresse est nettoyee automatiquement.
A savoir : cela masque un bouton, cela ne protege pas un secret. Quelqu'un qui
lit le code source peut retrouver ce parametre. C'est sans consequence : les
reglages ne changent que l'affichage sur son propre ecran.

Pour rendre vos essais definitifs : bouton « Copier le CSS » en bas du
panneau, puis collez le bloc obtenu a la place du bloc ":root{ ... }" au debut
de src/styles/global.css.


-------------------------------------------------------------------------
7. METTRE EN LIGNE
-------------------------------------------------------------------------
Netlify doit etre relie au depot GitHub : Site configuration > Build & deploy
> Continuous deployment > Link repository. Les reglages de construction sont
fournis par netlify.toml, il n'y a rien a saisir.

Ensuite, chaque enregistrement envoye sur la branche main declenche une
reconstruction et une mise en ligne, en une minute environ.

Si la construction echoue, Netlify garde la version precedente en ligne et
affiche le message d'erreur dans l'onglet Deploys. La cause la plus frequente
est un nom de fichier photo qui ne correspond pas a celui ecrit dans
src/data/series.ts : le message le dit explicitement.


-------------------------------------------------------------------------
8. CHANGER L'ADRESSE DU SITE
-------------------------------------------------------------------------
Une seule ligne : le champ "site" dans astro.config.mjs. Les apercus de lien,
l'adresse canonique et sitemap.xml en decoulent. Pensez a corriger aussi
public/robots.txt.
